# Tidepool – Landing Page

React 18 + Vite + Tailwind CSS 3 + lucide-react.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Structure
- `src/components/` – one file per section (Navbar, Hero, About, Features, HowItWorks, Testimonials, Pricing, Footer)
- `src/components/ui/` – reusable pieces (Button, Logo, Reveal, SectionHeading)
- `src/data/content.js` – all copy, plans and links in one place
- `tailwind.config.js` – colors (ink, tide, coral, mist) and fonts
